## balance-bot/（バランス検証のボット）

`run.mjs` が HTML を Playwright で開き、`bot.js`（下手・普通・上手の3段階）に gameAPI 経由で遊ばせて、1ゲーム1行の JSON に記録します。

```
cd balance-bot
node run.mjs --html ../../../game/frontier-war.html --games 40 --workers 4 --out results/run-1.jsonl
node analyze.mjs results/run-1.jsonl
```

- Playwright は、リポジトリの `mcp/node_modules`（`mcp` で `npm install` したもの）から読みます。
- `--html` を省くと、リポジトリの `game/frontier-war.html` を遊びます。
- `--tune` の置き換えは、点検したときの版（PR #3 の前）の HTML に合わせて作ったものです。今の本体では当たらないものがあり、当たらなければそこで止まります。
- `--tune tune/xxx.json` で、HTML の写しに文字列の置き換え（調整案）を当てて遊ばせられます。難易度の案（tune/xeno.json、tune/varga.json など）もここにあります。
