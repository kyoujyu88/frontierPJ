# 辺境星系戦記 ゲームバランス検証報告（シミュレーション）

**使い方（1行）**：遊ばせたい HTML のパスを `--html` に渡すと、3段階 × 40ゲームを回して集計を表示します。

```
cd /tmp/claude-0/-home-user-frontierPJ/00c9b965-31a0-5f90-ad0c-904132688cff/scratchpad/agents/balance && node run.mjs --html /home/user/frontierPJ/game/frontier-war.html --games 40 --workers 4 --out results/run-$(date +%s).jsonl
```

その他の使い方（どれも上のフォルダで実行）：

| 目的 | コマンド |
|---|---|
| 調整案を当てて回す（HTML の写しに置き換えを当てる。本体は書き換えない） | `node run.mjs --html <HTML> --tune tune/rec0p.json --games 40 --out results/x.jsonl` |
| 段階を絞る・ボットの方針を変える | `--levels normal,good`　`--overrides '{"capital":"avoid"}'`（`rush`／`formFixed:"crane"`／`refit:"none"` など） |
| ページに JS を差し込む（例：セラフ級を作れなくする） | `--patch patch/noseraph.js` |
| 結果ファイルを集計し直す | `node analyze.mjs results/x.jsonl` |
| 変種どうしを1表で比べる | `python3 -I compare.py 基準=results/a.jsonl 案=results/b.jsonl` |
| 1ゲームの経過を見る | `node trace.mjs normal 1001 --html <HTML> [--tune tune/rec0p.json]` |
| 調整案の JSON を数値から作る | `python3 gentune.py 名前 rSeraph=600 investCap=120 gate=0 mine=10 mineRich=20 survey=15` |

- 1ゲームおよそ 1 秒です（描画・効果音・待ち時間を止めた高速モード）。120ゲームが約1分で終わります。`--render` を付けると描画を止めません（遅くなります）。
- `--out` は**追記**です。毎回新しいファイル名にしてください。
- 乱数は `?seed=` で固定しています（種 1000〜）。同じ種・同じモードなら同じ結果になります。

## 0. 結論

1. **セラフ級なしでも巣を落とせます**（B-01・高）。セラフ級の研究を無効にしても、普通・上手は 100% 勝ち、勝つのも同じか少し早い（元の版：T17.2／T17.8、修正版：T18.9／T17.8）。設計の柱「セラフ級開発 → 総力戦」が数字の上では成り立っていません。
2. **総力戦（異生体が出てから勝つまで）が平均 1.6〜1.9 ターンしかありません**（B-02・高）。研究が安いのと、貯めた資金をその場で研究に全部注げるのが原因です。どちらのボットも 18 ターン前後で勝ちます。
3. **推奨の調整案 `rec0p`**（5項目・15か所の置き換え）で、次のように変わります。修正版でも確かめました。

   | 項目 | 調整前 | rec0p |
   |---|---|---|
   | 勝つまでのターン（普通） | T18.3 | T23.6 |
   | 総力戦の長さ（普通／上手） | 1.9／1.6 ターン | 6.3／4.5 ターン |
   | セラフ級なしでの勝率 | 100% | 0% |
   | 20ターン目の手持ち資金 | 560〜800 | 550 前後 |
   | 下手の勝率 | 62% | 57% |

4. **ほかに分かったこと**（中・低）
   - どの段階でも負けません（敗北 0%、主星を取られたことも 0 回）。
   - 「本星を落とすか、18ターンまで待つか」の選択で結果が変わりません。
   - 改装や陣形を変えても勝率はほぼ同じです。陣形の補正を2倍にしても変わりません。
   - 終盤に資金の使い道がありません。
   - 砲撃戦隊だけ勝率が大きく下がります。
   - 終わらない戦闘はまれです（0.1% 未満）。修正版のラウンド上限で決着がつき、逃げ回って時間切れを狙う手も得になりません。

## 1. やったこと

### 1.1 ボット（`bot.js`、ページ内で動作）

- **すべての操作は `window.gameAPI` 経由**で行います。画面のボタンと同じ検証を通ります。`setPace(0)` に加えて、`game-api.js` の待ち時間を 0 にしています。
- **状態の読み取りだけ**は、本体のグローバル（`S`、`B`、`reach`、`bestAttack` など）を直接見ています。
- 3段階の強さ：

| 段階 | 内政 | 改装・陣形 | 攻める判断 | 戦闘 |
|---|---|---|---|---|
| 下手 | 研究と造船はする。施設はでたらめな星にでたらめな種類。修理は5割を切ってから | いじらない（既定の割り振り・横陣） | 戦力を比べない。主力は1艦隊に固定。異生体が出たら巣へ向かう | 撃てる中で一番痛い攻撃。撃てなければ敵旗艦・中枢へ寄る |
| 普通 | 特性に合う施設（鉱物→採掘所、遺跡→研究所、要塞→衛星、工業→造船所）、研究、旧式艦の置き換え、修理、探査 | 役割を固定（旗艦・砲撃・爆撃×2）、方陣 | 戦力比 1.1 以上で攻める。主星の守り、到達2手先は中継の星で待つ | 優先度つきの貪欲法（とどめ・旗艦・側背面を優先。爆撃艦は中枢優先）。撃てなければ敵旗艦の隣のマスへ |
| 上手 | 普通に加えて、遺跡研究所を先に建てる、セラフ級を最優先、脅威の大きい星の防衛修復 | 戦闘の前に目的に合わせて改装（惑星・巣は爆装、艦隊戦は主砲と装甲）。陣形は敵の型で選ぶ（砲撃→楔形、重装・戦列→鶴翼、突撃・強襲→方陣） | 戦力比 1.2。敵の進路を読んで待ち伏せ | 普通に加えて、敵の射程の外で待つ間合い取り。旗艦は後ろに置き、危なければ退く |

- **共通の判断**
  - 本星の扱い：攻める・避けるを切り替えられます。既定は「落とせるなら落とす」です。
  - セラフ級が使えるのに艦隊に1隻もないときは、造船所へ戻って作ります。
  - 艦隊戦に勝ったあと、敵や中立の星にとどまった艦隊は、その場から攻略します（修正版の `moveFleet(to=今の星)`）。
  - 中枢を傷つけられる艦がいない攻略戦からは退きます。
- **終わらない戦闘への対策**（指示どおりボット側に入れました）
  - 3ラウンド続けて誰も損害を受けなければ、間合い取りをやめて前へ出ます。
  - 6ラウンド続けば撤退します。
  - 30ラウンドを超えた戦闘は打ち切ります。
  - それぞれの回数を記録しています（§5）。

## 3. 問題点

### B-01 セラフ級なしで巣の中枢を割れる（設計の柱が成り立たない）

- **重大度**：高
- **場所**
  - `bestAttack()`：SNAP 976行／修正版 1077行 `if(t.core&&!w.core&&att.side==="P")continue;`。爆装なら艦級を問わず中枢に当たります。
  - 巣の中枢の生成：`startBattle()` 内、SNAP 903行／修正版 996行。
- **何が起きるか**
  - アークライト級の爆撃艦で巣を割れるので、セラフ級の研究と建造は無くてもよい寄り道になっています。
  - 研究ドキュメントの流れ「異生体ゾア → セラフ級開発 → 総力戦」のうち、「セラフ級開発」が抜けても勝てます。
- **再現**（確認済み）：`--patch patch/noseraph.js`（`CLASSES[4].research=999999;`）で回しました。

  | 条件 | 普通 | 上手 |
  |---|---|---|
  | SNAP（各40ゲーム） | 100% 勝ち・T17.2 | 100% 勝ち・T17.8 |
  | SNAP・セラフ級あり（比較用） | T17.7 | T18.0 |
  | 修正版（各20ゲーム） | 100% 勝ち・T18.9 | 100% 勝ち・T17.8 |

  - セラフ級を待たない旧版のボットでは、普通の巣の勝利の 42% がセラフ級なしでした。
- **「中途半端に弱める」では足りないことも確かめました**（SNAP、セラフ級を作れなくして巣を強行させた場合）。セラフ級以外の爆装に倍率をかけて試しています。
  - 倍率 0.5：普通 100%・T21.9、上手 100%・T19.0。セラフ級を待つ場合（T25.1／T21.7）より**早い**です。セラフ級が作れる条件で強行させても、巣の勝利の 62〜70% がセラフ級なしで、勝つのも早くなります（T22.4／T19.1）。つまり「アークライトで巣へ急ぐ」が一番強い手のまま残ります。
  - 倍率 0.25：普通 10%、上手 40% 勝ち（T35〜40）。
  - 倍率 0（セラフ級の爆装しか通らない）：普通・上手とも **0%**。修正版でも 0%。
- **直し方の案**（修正版の行番号）
  - 996行の中枢に印を付けます：`const core={uid:uid(),side:"E",core:true,hive:isHive,name:...`
  - 1077行の次に、次の1行を足します：

    ```js
    if(t.hive&&att.side==="P"&&!att.anti)continue; // 巣の中枢はセラフ級の爆装でしか割れない
    ```

    - `dmg` の式（1080行）に倍率をかけても、1084行の `Math.max(1,…)` で最低 1 点が入るので、0 にしても当たってしまいます。`continue` で対象から外す必要があります。
  - 説明文も合わせて直します。
    - 513行、1007行の「巣の中枢★は爆装でしか…」→「セラフ級の爆装でしか…」
    - 1008行の「爆装がない」注意を、巣ではセラフ級の有無で出すようにします。
    - 異生体出現時の技術局の台詞（945行）に「巣の中枢を割れるのはセラフ級だけ」を足します。
  - 検証で使った置き換えは `tune/rec0.json` のうち `HIVE_NONANTI` 関係の4つです。`const HIVE_NONANTI=0` を置き、`hive:isHive` を付け、上の `continue` を足し、`dmg` に倍率をかけます。ボットは `HIVE_NONANTI` の有無で関門を知るので、別の書き方で入れる場合は `bot.js` の `nonAnti()`（189行）も合わせてください。

### B-03 誰も負けない（どの段階・どの基準でも敗北 0%）

- **重大度**：中
- **場所**
  - 異生体の強さ：`makeXeno()` 修正版 346〜349行、`unitFromXeno()` 973〜977行
  - 湧き：867行
  - ヴァルガの増援：834行
- **何が起きるか**
  - 下手のでたらめな内政と突っ込むだけの戦闘でも、60ターンで一度も主星を取られません。下手は「勝てずに60ターン」で終わるだけです。
  - 異生体との艦隊戦の勝率は 90〜99% で、普通・上手の損害は艦隊耐久の 4〜10% です。
- **再現**（確認済み）
  - 基準：SNAP 180ゲーム・修正版 120ゲームで、主星を取られたのは 0 回でした。
  - 推奨案 rec0／rec0p：修正版 240ゲームでも 0 回でした。
  - 強さを上げる案（`tune/xeno.json`：ブルード 64・ドローン 34・装甲 5/4・攻撃 9/8・巣 240・最初の群れ3・上限 3/4）
    - 下手は 62% 負け（主星を取るのは異生体）。
    - 普通と上手は 100% 勝ちのまま（T18.2／T18.6）。
  - ヴァルガの増援を強める案（`tune/varga.json`）：下手 5% 負け、普通・上手は 100%。
  - 両方（`combo1`）：普通 25% 負け、下手 95% 負け。
- **直し方の案**
  - 異生体を強くすると下手だけが詰み、普通以上には効きません。既定値を上げるより、**難易度の選択**にするのがよいと考えます。
  - 例：「難しい」は `xeno.json` の数値、「とても難しい」は `combo1`。`newGame()` に難易度引数を足し、上の各行の定数を `DIFF[...]` から引く形です。

## 6. ボットの限界（数字の読み方）

- **下手の数字は「最低限の遊び方」の下限**です。
  - 旗艦を先頭に突っ込み、改装も陣形も変えません。
  - 施設はでたらめで、資金が貯まりやすい書き方です。
  - 人間の初心者はこれより良く遊ぶはずです。調整の副作用（下手だけ詰む）の検出に使いました。
- **普通・上手は人間の上級者ほど強くありません。** それでも 100% 勝つので、普通以上の難しさを測るには向きません（B-03）。
- **ボットの方針そのものが数字を動かします。**
  - 例：旧版の普通はセラフ級を待たずに巣へ行っていたので、「セラフ級なしで巣を落とした」が 42% でした。今の版は、セラフ級があれば作るので 5% です。
  - B-01 は、ボットの方針に頼らない試し（セラフ級を消す／巣を強行させる）で確かめています。
- **施設の建て方はボットの決まりで決まります。** 「使われない施設」（対空砲 0.7、造船所 1 など）はボット側の結果なので、問題点には入れていません。
- **修正版は並行して直されています。** 修正版の数字は 09:07 の版で取りました。
