## ST-06【中】迎え撃つのは同じ星の1艦隊だけ。負けると、もう1艦隊が居るのに星を奪われる

- 場所: `endTurn()` 770行・788行 `const pf=fleetsAt(to,"P")[0];`（配列で先にいる艦隊を選び、強さは見ない）。773行の様子見の判定も、この1艦隊の戦力だけで決まる。`closeBattle()` 1131行は、その星に他の自軍艦隊が残っていても siege する。
- 何が起きるか: 弱い艦隊（編成したばかりのラーク1隻など）と主力が同じ星にいると、弱いほうが迎え撃つ。負けると弱いほうは主星へ戻り、敵は主力のいる星を攻めて占領する。主力は敵の星の上で敵艦隊と同居することになる（迎撃はできる）。様子見も弱いほうの戦力で決まるので、主力がいても敵はひるまない。
- 再現（確認済み・両方）: `s3.mjs`。オルドに第2艦隊（耐久3×2、戦力2）と第1艦隊（戦力16）を置き、第2艦隊を配列の前にした。突撃のヴァルガ前衛が来ると、迎え撃ったのは第2艦隊だった。負けたあとは `owner4:"E"`、`at4:["E:ヴァルガ前衛","P:第1艦隊"]`。
- 直し方の案:
  - 迎え撃つのを一番強い艦隊にする: `const pfs=fleetsAt(to,"P").sort((a,b)=>fleetPower(b)-fleetPower(a)),pf=pfs[0];`。様子見は `pfs.reduce((s,x)=>s+fleetPower(x),0)` で判定する。
  - closeBattle の防衛戦の後始末を `const others=fleetsAt(cfg.node,"P").filter(x=>x!==pf); if(!cfg.attack&&S.fleets.includes(ef)&&!others.length){ef.node=cfg.node;siege(...)}` にする。残っている艦隊がいれば、敵は入れない（残りの艦隊と続けて戦わせてもよい）。主星での防衛では pf 自身が主星に残るが、filter で外しているので、今の動き（主星が攻められる）は変わらない。

## ST-07【中】休戦の開始時に自国の星に居座っていたヴァルガ艦隊が、その星をふさぎ続ける

- 場所: 休戦中は 762行 `if(!S.truce)` でヴァルガが一切動かない。`intruder()` 576行は休戦中のヴァルガを迎撃の相手から外す。`orderMove()` 630行は、`fleetsAt(to,"E").length` があれば自国の星でも入らせない。`checkMonsterTrigger()` 847行で休戦が始まるときに、居場所の後始末をしていない。
- 何が起きるか: ヴァルガ艦隊は、自国の星を攻めて落とせなかったとき（siege の失敗）、そのターンはその星に残る。ターン18の移動でそうなった艦隊は、休戦でその場に固定される。
  - 自軍はその星へ、隣からの移動も亜空間移動もできない。迎撃ボタンも出ない。異生体がたまたま通って呑み込むまで続く。
  - 主星で起きると、どの艦隊も主星へ戻れない。
  - ただし、撤退・敗北したときの `pf.node=HOME`（1130行）は休戦を見ないので、その主星へワープして同居できてしまう。
- 再現（確認済み・両方）:
  - `s15.mjs`（SNAP）: ターン17に、ヴァルガ前衛をミラに置き、リュネに衛星を置いて防衛力40にした。endTurn 後は `truce:true, efNode:1, owner1:"P"` で、リュネに居座った（この例では3ターン後に異生体が来て呑み込んだ）。
  - `s12.mjs` 後半: 主星での防衛戦で撤退すると、ヴァルガ前衛が主星に入る（攻め落とせない）。次のターン（18）に休戦。`moveOptions` の主星は `"不可（ヴァルガとは休戦中）"` で、`moveFleet` も失敗する。3ターン進めても `efNode:0` のままだった。
- 直し方の案: 休戦が始まるとき、自国以外の星にいるヴァルガ艦隊を自領へ戻す。
  ```js
  if(S.truce)S.fleets.filter(f=>f.side==="E"&&planet(f.node).owner!=="E").forEach(f=>{
    const p=bfsPath(f.node,n=>planet(n).owner==="E");f.node=p?p[p.length-1]:CAPITAL;log(`${f.name}は自領へ引き上げた。`)});
  ```

  （別案として、休戦中でも「自国の星にいるヴァルガ艦隊」だけは迎撃できるようにしてもよい。）

## ST-10【中】hot snapshot の保存・復元で状態が壊れる

- 場所: 1655行 `window.claude?.hot?.snapshot?.(()=>({S:B?null:S}))`、`start()` 1652〜1654行（作業中の版では、hot の S があればそれを使い、無ければ自動保存を読む）。
- 何が起きるか:
  1. 敵ターンの途中（ANIM.busy の間）は B が null なので、処理の途中の S をそのまま返す。復元すると、ターンは進んで収入も入っているのに、キューに積まれた防衛戦（ローカル変数の queue）と研究所の加算は消えている。敵が攻めてこなかったことになる。作業中の版でも、hot の S が自動保存より先に使われるので同じことが起きる。移動アニメの途中を保存すると、`moved=true` なのに元の星にいる状態になる。
  2. 敗北・勝利（`S.over`）の状態を復元すると、結果画面が出ない。ほとんどのボタンが消えたまま、何の説明もない（「最初から」だけ使える）。
  3. 戦闘中（終わって作戦卓に戻る前も含む）は `S:null` を返す。SNAP では、復元すると `newGame()` になり、それまでのゲームが全部消える。作業中の版では、自動保存から「続きから」（戦闘前の状態）になるので実害は減った。ただし localStorage が使えない環境では、今もゲームが消える。
- 再現（確認済み）:
  - `s11.mjs`・`s11b.mjs`（SNAP。`window.claude.hot` の代わりを addInitScript で入れた）: 戦闘中に保存すると `{"S":null}` になり、ターン12・資金777 から復元すると `turn:1, funds:160` に戻った。敵ターンの途中に保存すると `snapTurn:2, snapFunds:320` で、オルドを攻めるはずの防衛戦は保存されず、ヴァルガ前衛はクオンにいるままだった。
  - `n1.mjs`（作業中の版。webdriver=false にして自動保存を有効にした）:
    1. 戦闘中の保存は「続きから（ターン12・資金777）」になる。
    2. 敵ターンの途中の保存は `turn:13, b:false, varga:[9,6]` で、途中の状態から始まる。
    3. 敗北状態は `over:"lose"` なのにモーダルが出ない。
- 直し方の案: 自動保存と同じ「区切りのよい時点の写し」を hot にも渡す。作業中の版には `lastSave`（autosave が最後に保存した JSON 文字列）があるので、それを使う。
  ```js
  window.claude?.hot?.snapshot?.(()=>({S:lastSave&&lastSave!=="over"?JSON.parse(lastSave):null}));
  ```
  あわせて、`start()` で `S.over` を読み込んだら `showEnd(S.over==="win")` を呼ぶ（または over の S は受け取らない）。

- 場所: `renderSide()` 476行 `+${labRate()}`、game-api.js 142行 `labPerTurn:labRate()`。実際に足す量は 748行 `researchOpen()?labRate():0`。
- 何が起きるか: アークライト級が完成してから異生体が出るまでは、研究が開いていないので研究所の分は入らない。それでも表示は「+10」のまま。さらに、ターン終了の頭で `lr` が 0 と決まるので、異生体が出たそのターンの研究所の分も入らない。
- 再現（確認済み・両方）: `s12.mjs`。`tier:3` で `researchOpen:false` のとき、表示は「研究所から毎ターン +10」、API は `labPerTurn:10` だった。1ターン進めても研究は増えなかった（`researchGained:0`）。
- 直し方の案: 表示は `researchOpen()?labRate():0` にして、止まっているときは「（研究停止中）」を添える。API も同じにする。研究所の分は、ターンの終わりで `researchOpen()` を見直してから決める。

## ST-15【低】異生体が防衛戦に勝って星に入っても、ヴァルガ艦隊を呑み込まない

- 場所: `closeBattle()` 1131行は `ef.node=cfg.node;siege(...)` だけ。呑み込みの処理は、移動のときの 792行にしかない。
- 何が起きるか: 自軍とヴァルガ艦隊が同居している星で、異生体との防衛戦に負けるか撤退した場合の話。異生体はその星に入って浸食するが、ヴァルガ艦隊は残り、E と M が同居する。
- 再現（確認済み・両方）: `s17.mjs` の S18。結果は `owner4:"M"`、`at4:["E:ヴァルガ残党","M:異生体の群れ"]`。

## ST-17【低】造船所の「旧艦と置換」が、知らせずに旗艦を置き換える

- 場所: `openYard()` 707〜709行。同じ艦級が並んでいると番号の小さい艦を選ぶので、旗艦（0番）が選ばれやすい。game-api.js 386行も同じ選び方をしている。
- 何が起きるか: 旗艦が一番古い艦級だと、旗艦が置き換わる。旗艦用にした改装（例: 装甲4・爆装2）は標準の振り分けに戻る。ボタンには「旧艦と置換（実費36）」としか出ず、どの艦が置き換わるのか分からない。
- 再現（確認済み・両方）: `s16.mjs`。旗艦がラーク級（装甲4・爆装2、耐久3）、2番艦がファルコ級の艦隊で、ファルコ級の「旧艦と置換」を押した。結果は `flagReplaced:true`、振り分けは標準の `{sh:3,ca:3,mi:1,bo:1,sp:1}`。
- 直し方の案: 同じ艦級なら随伴艦を先に選ぶ（後ろから探す）。ボタンに対象を出す: `旧艦（${CLASSES[f.ships[worst].cls].name}${worst===0?"・旗艦":""}）と置換`

## ST-19【低】同居したヴァルガ艦隊は、自軍艦隊を攻めずに出ていく

- 場所: `endTurn()` のヴァルガのループ（769〜779行）。`vargaPath()` は今いる星を目的地から外し（`bfsPath` の `n!==from`）、攻めるかどうかは次の星 `path[0]` の自軍艦隊でしか決めない。
- 何が起きるか: 自軍艦隊が敵の星に居座り、そこにヴァルガ艦隊も同居していることがある（ST-06 の結果や、本星の増援が湧いたときなど）。このとき、突撃戦隊であってもヴァルガ艦隊は自分の星の自軍を攻めず、隣の自国の星を攻めに出ていく。自軍は居座ったまま、敵が出ていったあとに assaultHere で攻略できてしまう。
- 再現（確認済み・作業中の版）: `n3.mjs`。敵の星オルドに、第1艦隊と突撃戦隊のヴァルガ前衛を同居させて endTurn した。戦闘は起きず `efNode:1`（リュネを攻撃しに出た）、`f1Node:4` のままだった。
- 直し方の案: ヴァルガの手番の最初に `const pf0=fleetsAt(f.node,"P")[0]; if(pf0){queue.push({kind:"fleet",pf:pf0,ef:f,node:f.node,attack:false});continue}` を入れる（様子見の判定を挟んでもよい）。
