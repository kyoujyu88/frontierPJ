# 辺境星系戦記 公開用のサムネイル・紹介動画・スクリーンショット

itch.io のページで使う素材です。どれもゲームの画像（game/art）・BGM（game/audio）と、実際のゲーム画面の録画から作っています。

| ファイル | 中身 | itch.io での使い道 |
|---|---|---|
| `cover_630x500.png` | サムネイル（630×500） | 「Cover image」。itch.io の推奨サイズ |
| `cover_1260x1000.png` | 同じ絵の2倍サイズ | 高解像度の画面向けに、こちらを Cover image にしてもよい（比率は同じ） |
| `thumb_1920x1080.png` | 16:9 のサムネイル | 紹介動画を YouTube に上げるときのサムネイル |
| `screenshots/*.jpg` | ゲーム画面 6枚（1920×1080） | 「Screenshots」（星図・改装・艦隊戦・異生体出現・巣への突入戦・勝利） |
| 紹介動画 `trailer.mp4` | 約56秒・1920×1080・30fps・BGMつき | itch.io は動画を直接置けず、YouTube か Vimeo の URL を「Gameplay video or trailer」に入れる。YouTube に限定公開で上げて URL を貼れば足りる |

紹介動画は約23MBあるのでリポジトリには入れていません。共有フォルダの `promo/trailer.mp4` にあり、下の手順で作り直せます。

## 注意

- 原作の名前は、画像・動画・テロップのどこにも出していません。
- 画像と BGM は生成AI（Gemini・Lyria）で作ったゲーム素材をそのまま使っています。itch.io の生成AI開示欄では「画像・音声」に生成AIを使ったと申告してください（research/platform-release.md）。
- ゲーム画面はボットに遊ばせた1ゲーム（seed 1）の途中経過から場面を再現して撮っています。画面はすべて実際のゲームのものです。

## 作り直す手順

必要なもの: Node.js 20 以上、Python 3（Pillow・fonttools・brotli）、ffmpeg、mcp/ の `npm install` 済みの Playwright（Chromium）。

```sh
# 1. ローカル版を作る（撮影はこのフォントと音を使う）。フォントの元ファイル local/_src/fonts/*.ttf が必要
python3 local/build_local.py

cd promo/tools
# 2. 検証ボットに1ゲーム遊ばせて、毎ターンの途中経過を保存（research/…/balance-bot/bot.js を使う。--bot で場所を指定できる）
node snaps.mjs
# 3. 場面ごとに録画（約6分）。node shoot.mjs battle のように場面だけでも撮れる
node shoot.mjs
python3 assemble.py
# 4. サムネイル・テロップを作り、動画を組み立てる（スクリーンショットもここで書き出す）
python3 gfx.py
python3 build.py      # → promo/work/trailer.mp4
```

テロップの文言は `gfx.py` の末尾、場面の切り出し位置・速さ・長さは `build.py` の `SHOTS`、撮影の操作は `shoot.mjs` にあります。作業ファイルは `promo/work/`（git には入れない）に出ます。

録画は Chromium の画面転送（CDP の screencast）で撮っています。headless では CSS ピクセルの大きさでしか届かないため、1280×720 のレイアウトを CSS の zoom で 1.5 倍にして 1920×1080 で撮っています（星図だけは 1920 幅のレイアウトのほうが見やすいので zoom なし）。
